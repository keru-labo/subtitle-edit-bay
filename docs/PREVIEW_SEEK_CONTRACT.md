# プレビューのシーク受入条件

[試作のインターフェース](../src/preview/playback_backend.h) は再生、停止、一時停止、シーク、音量、ミュート、位置とエラーの通知を定義します。統合時はアダプター生成時に入力と映像出力先を渡し、素材オープンやデバイス喪失の通知はセッション単位で扱います。シークの世代は素材を開いた後のフレーム、PCM、位置通知に使います。

| 条件 | Given / When / Then |
| --- | --- |
| 連続スクラブ | デコード開始前に A と B を要求した場合、B の時刻と素材だけを処理する |
| 遅延した結果 | A を処理中に B が到着した場合、それ以降の A の映像・音声を公開しない |
| 通常再生へ復帰 | プロキシで目的位置に到達した状態でスクラブを終えた場合、同じプロジェクト時刻を元動画へ要求し、新しい世代へ切り替える |
| 停止・素材変更 | 処理中の結果と未処理シークがある状態で無効化した場合、両方を破棄する |

[ネイティブテスト](../tests/preview/seek_gate_test.cpp) は要求・配信許可を検証します。バックエンドへの統合時は、シーク受付、作業取り出し、表示・音声キュー投入直前の世代確認を同じ所有スレッドで順序づけます。既にデバイスへ渡した音声は、シークや停止の境界でキューをフラッシュします。

Linux で GCC・gcov・Python 3 を使って行カバレッジと、古い世代の受け入れ・未発行世代の受け入れ・先着優先・無効化時のキュー残留の変異を検査します。

```sh
python tests/preview/check_seek_gate.py
lean tests/preview/SeekGate.lean
```

[Lean 4.19.0 の証明](../tests/preview/SeekGate.lean) は、自然数の世代モデルで旧世代の拒否、最新要求の取り出し、無効化を検査します。C++ の `uint64_t` 実装との対応は世代番号が周回しないセッションを前提とし、メディア処理やスレッドの実装はネイティブテストと実機検証の対象です。
