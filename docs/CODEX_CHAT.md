# Codexチャット

> - **種別**: 利用ガイド
> - **想定読者**: 利用者
> - **対応機能 / 正本コード**: AI チャット、字幕編集提案（`backend.ai`）
> - **最終確認**: 2026-11-17

## セットアップ

Codexチャットは公式Python SDK `openai-codex==0.163.0` を使用します。SDKと同じ固定版のCodex本体も、アプリのセットアップで導入されます。Codex CLIやCodex Desktopを別途導入する必要はありません。PATHの探索や `CODEX_EXECUTABLE` による実行ファイル指定は使用しません。

SDKが `codex app-server` をローカル子プロセスとして起動し、stdioで通信します。通信・プロセス管理・通知の振り分けはSDKが担当します。仕様は[公式SDKドキュメント](https://developers.openai.com/codex/sdk)と[App Serverドキュメント](https://developers.openai.com/codex/app-server)を参照してください。

既存のCodex認証はSDKが標準の保存先から再利用します。未ログインの場合は、下記のログイン操作を行います。WindowsでもSDK標準のプロセス起動を使い、アプリ独自の非表示起動ラッパーは追加しません。

チャット画面はprovider-neutralな `AIProvider` 境界だけを参照します。現在の実装では `CodexAIProvider` がCodex App Serverの認証、モデル、thread、turn、ストリーミング通知を共通の状態・イベントへ変換します。GUIやQMLはCodex固有のRPC名を参照しないため、追加providerは同じ境界のadapterとして実装できます。AIパネルではproviderを切り替えられ、現在はCodexとGemini ACPに対応します。この文書は主にCodex利用時の手順を説明します。

## ログインとログアウト

1. 編集プロジェクトを開き、画面右上の `AIログイン` を押す（右インスペクターが `AI Codex` タブに切り替わります）
2. タブ内の `Codexログイン` を押す
3. 開いたブラウザでChatGPTの認証を完了する
4. ログインが完了すると、タブ内にチャットが表示されます

編集プロジェクトを開いていない場合は、画面右上の `AIログイン` を押すとそのままログインが始まります。

ブラウザが自動で開かない場合は、認証待ちの間に表示される `ブラウザを開く` を押してください。アカウントを切り替える場合はパネル内の `再ログイン`、利用を終了する場合は `ログアウト` を使用します。

表示する状態は、接続中、未ログイン、ログイン待ち、ログイン済み、認証エラー、切断です。切断した場合は `再接続` を押し、必要に応じて再ログインしてください。Codexへ接続できない場合も、通常の文字起こし、字幕編集、音量調整、書き出しは引き続き利用できます。

## チャットとモデル

ログイン後にパネルを開き、App Serverから取得した利用可能モデルを選択してメッセージを送信します。応答は受信した部分から順に表示されます。送信中、応答受信中、停止中、送信失敗はパネル上部に表示され、処理中は `停止` を使用できます。

モデルは固定リストではなく `model/list` の結果から表示します。一覧が複数ページに分かれる場合も、すべて取得してから保存済みモデルの利用可否を判定します。選択したモデルはローカルの `.gui/runtime_config.json` に `shared.codex_model` として保存され、アプリ再起動後も使用されます。各送信の `turn/start` に選択モデルを指定するため、変更は次のメッセージから反映されます。保存済みモデルが利用できなくなった場合はエラーを表示し、App Serverが示す既定モデルへ切り替えます。

`新規` は画面内の会話を消去し、新しいCodex threadを次の送信時に開始します。会話本文はGUI設定へ保存しません。

字幕の編集依頼は、通常チャットとは別の安全な提案経路へ自動的に振り分けます。`自動` では、選択中の字幕があればその字幕、なければ再生位置の字幕を対象にします。`選択字幕`、`再生位置`、`時間範囲`、`全字幕` を選ぶと対象を明示できます。生成された変更案はチャット内のカードで確認し、変更単位で選択してから `選択した変更を適用` を押してください。

この字幕編集経路はComputer Useや画面の自動クリックを使用しません。Subtitle Edit Bayが字幕ID、時刻、本文、話者、字幕設定だけを構造化contextとして渡し、返された提案を検証して表示します。通常チャットへ誤って送られる場合は、対象選択を `自動` 以外にすると字幕編集経路を明示できます。

## 字幕編集の提案

字幕編集の提案は、字幕本文・時刻・話者・フォントなどの編集案を生成し、利用者が差分を確認してから適用する機能です。

- 送信されるのは選択した字幕のID、時刻、本文、話者、字幕設定だけです。動画・音声ファイルそのものと、プロジェクトの絶対パスは送信しません。
- 編集案はプロジェクトへ直接書き込まれません。`送信`、差分確認、`適用` の順で操作し、適用前は元プロジェクトとファイルを変更しません。

使い方:

1. 編集プロジェクトを開き、右インスペクターの `AI Codex`（共通サイドバーの `Codexチャット`）を開く
2. `自動`、`選択字幕`、`再生位置`、`時間範囲`、`全字幕` から対象範囲を選ぶ
3. 依頼文を入力して `送信` する
4. チャット内に表示された字幕ごとの差分、警告、対象件数を確認する
5. 変更を選択して `選択した変更を適用`、または `破棄` する
6. 適用後に字幕一覧、プレビュー、タイムラインを確認して保存する

Codexが処理中に手動編集を行った場合はrevision競合として提案を適用しません。現在の状態を確認してから再送信してください。適用後も、保存、Undo/Redo、ASS更新、動画書き出しは明示的に操作してください。

音量調整の提案（`propose_audio_mix`）も、同じように型付きActionとして差分確認を経て適用します。Actionの契約は [CODEX_ACTIONS.md](CODEX_ACTIONS.md) を参照してください。

制約:

- CodexによるプロジェクトJSONの直接編集は行わない
- 確認なしの自動適用、自動レンダリングは行わない
- 字幕編集提案の対象は字幕のみで、音量・ショート動画の編集そのものは対象外（音量は上記の提案Actionとして扱う）
- リモートWebSocket接続と、Codexアカウント・APIキーの独自管理は対象外

## セキュリティと機能境界

- ChatGPTのtokenやAPIキーはアプリで受け取らず、Codex CLIの管理する認証フローを使用する
- 認証URL、token、会話本文を `.gui/runtime_config.json` や通常ログへ書き込まない
- App Serverとはstdioで接続し、チャットthreadは `approvalPolicy=never`、`sandbox=read-only` で開始する
- 各turnは `sandboxPolicy={type: readOnly, networkAccess: false}` で実行し、ファイル書き込みとネットワークアクセスを許可しない
- 現行stable App Serverのread-only sandboxはローカルファイルの読み取り範囲をworkspaceだけに限定しないため、機密ファイルを含むworkspaceではチャットを使用しない
- コマンド実行やファイル変更のapproval要求を自動承認しない
- コマンド・ファイル変更の承認要求には明示的に拒否を返し、入力要求やMCP elicitationなど未知の要求では接続を閉じてエラーにする

通常の質問は読み取り専用チャットへ送信します。字幕の編集依頼は型付き `propose_subtitle_edit` Actionへ振り分け、差分確認と明示適用を共通チャット内で扱います。提案をプロジェクトへ直接書き込ませたり、Codex出力だけで対象範囲や確認済み状態を拡張したりしません。

接続・通常のAPI応答は30秒、編集案の生成は120秒でタイムアウトします。期限超過時にはSDK接続を閉じ、再接続では新しいクライアントを作成します。編集案の差分確認・適用・Undoはアプリ側で行います。SDKへの移行により、動画完成までの自動操作やMCP操作ツールが追加されることはありません。

失敗時はGUIの処理ログから、SDKのバージョン、接続状態、Turn状態、エラーをコピーできます。診断情報にはredaction後の値だけを含め、字幕本文と認証情報は通常のコピー内容へ含めません。

## 受け入れ条件・確認方法

- **ログイン**: 未ログイン状態からログイン操作を行い、表示が `ログイン済み` に変わること。Codexへ接続できない場合も、通常の文字起こし、字幕編集、音量調整、書き出しが利用できること。
- **チャット**: モデル一覧から選択したモデルで送信でき、応答が順に表示され、`停止` で止められること。
- **字幕編集の提案**: 対象範囲を選んで送信すると差分カードが表示され、適用するまでプロジェクトが変わらないこと。適用後は字幕一覧とプレビューへ反映され、Undoで戻せること。処理中の手動編集では競合として適用されないこと。
- **異常時の切り分け先**: 接続・認証のエラーは [TROUBLESHOOTING.md](TROUBLESHOOTING.md) を参照する。
